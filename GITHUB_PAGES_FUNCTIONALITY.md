# 🔍 Что работает на GitHub Pages

## ✅ Что БУДЕТ работать:

### 1. **Подключение Keplr кошелька** ✅
- Полностью работает в браузере
- Не требует сервера
- Можно подключиться к любой сети (Juno, Osmosis, Cosmos Hub и т.д.)

### 2. **Запросы к смарт-контракту (Query)** ✅
- `get_config` - получение конфигурации контракта
- `get_participant_status` - статус участника
- `get_stats` - статистика распределения
- Все запросы работают через CosmJS прямо из браузера

### 3. **Транзакции к смарт-контракту (Execute)** ✅
- `register_participant` - регистрация участника
- `submit_task` - отправка задания
- `validate_task` - валидация задания (только для issuer)
- `claim_reward` - получение награды
- `deposit` - пополнение контракта (только для treasury)
- Все транзакции подписываются через Keplr

### 4. **Автоматическое демо** ✅ (обновлено!)
- Теперь автоматически переключается на офлайн-режим, если сервер недоступен
- Работает полностью в браузере без сервера
- Показывает логи и статистику

### 5. **Ручное распределение (Manual Demo)** ⚠️
- **Частично работает**: форма ввода работает
- **Не работает**: демо-симуляция (требует сервер `localhost:8787`)
- **Решение**: можно использовать для реального взаимодействия с контрактом через Keplr
