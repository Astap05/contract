# Pocket Flow Demo

Этот каталог демонстрирует, как **Pocket Flow** (минималистичный LLM/агентный фреймворк) можно встроить в наш проект распределения токенов.

## Что такое Pocket Flow

- **Graph + Shared Store.** Весь рабочий процесс описывается как ориентированный граф узлов и общая память между ними.
- **Минимум кода.** Базовое ядро помещается в файл `core.mjs` (≈120 строк). Можно встраивать прямо в проект без зависимостей.
- **Гибкость.** В узлах можно вызывать LLM, REST API, писать бизнес-логику и комбинировать их.

Pocket Flow идеально подходит, когда нужно автоматизировать пошаговый сценарий (например, распределение токенов по участникам, сбор данных, валидация результатов) и дать ИИ или пользователю возможность вмешиваться на отдельных этапах.

## Как устроена интеграция

1. **`core.mjs`** – собственная реализация ядра Pocket Flow (SharedStore + Graph + Node).
2. **`run-demo.mjs`** – сценарий, который:
   - спрашивает у пользователя параметры демо;
   - проверяет, что поднят наш demo-сервер (`frontend npm run dev`);
   - запускает поток событий распределения (`/demo-fast`);
   - собирает логи и готовит сводку.
3. **`package.json`** – отдельный npm-пакет для удобного запуска.

## Запуск

```bash
cd pocket-flow
npm install          # установка не требуется, но создаст lockfile
npm run demo
```

Во время запуска скрипт задаст три вопроса (участники, токены, denom) и покажет, как Pocket Flow пошагово управляет процессом.

> ⚠️ Перед запуском убедитесь, что фронтенд проекта запущен (`frontend/npm run dev`) – именно он поднимает demo-сервер на `http://localhost:8787`.

## Как расширять

- **Добавить LLM.** Внутри любого узла можно вызвать модель (OpenAI, Llama, и т.д.), прочитать/записать данные в `ctx.store`, передать результаты дальше.
- **Контроль задач.** Узлы легко комбинировать: валидация заявок, уведомления, запуск CosmWasm-скриптов.
- **UI-интеграция.** Сценарий можно дергать с фронтенда (через API), подключить визуализацию графа.

## Связь с проектом

Pocket Flow демонстрирует “мета-уровень” — как автоматизировать сценарий распределения токенов. В текущем проекте:

- `frontend/src/ui/App.tsx` визуализирует статистику и процесс;
- `frontend/server.mjs` генерирует поток событий;
- `pocket-flow/run-demo.mjs` оркестрирует эти шаги и готовит отчёт.

Этот шаблон можно расширить, чтобы AI-агенты помогали в модерации заданий, генерации отчётов, анализе логов и т.д.
